# AI-Powered Smart Road Safety & Accident Prevention System — Frontend

This folder contains the current HTML/CSS/JavaScript frontend prototype.

## Run

Open `index.html` with VS Code Live Server. Sign In and Sign Up are available from the dashboard.

## Current implementation

- Dashboard with all eight project modules
- Real Leaflet/OpenStreetMap live map
- Browser GPS tracking
- Live location marker and accuracy area
- OpenStreetMap destination search and OSRM route preview
- Spring Boot API integration hooks for authentication/profile
